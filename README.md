📌 Project Title

🫀 Heart-Guard — AI-Powered Heart Disease Detection & Risk Analysis Platform

📖 Description

Cardiovascular diseases remain one of the leading causes of death worldwide. Early detection and risk assessment are critical for timely medical intervention. Traditional diagnosis relies heavily on manual analysis and clinical expertise, which can be time-consuming and subjective.
This project presents an AI-powered heart disease prediction system that analyzes patient clinical parameters, estimates disease risk using machine learning, and provides explainable predictions through modern XAI techniques.
The system is designed as a medical decision-support tool, combining accuracy, transparency, and usability through an interactive dashboard.

📖 Project Overview

Heart-Guard is a full-stack AI application that predicts the likelihood of heart disease based on patient health data such as age, blood pressure, cholesterol, ECG results, and stress test outcomes.

The platform integrates:

A trained ML model for prediction

SHAP-based explainability for trust

A real-time dashboard for clinicians

Downloadable AI-generated medical reports

The system is fully deployed and cloud-accessible.

🧪 Decision Logic (Core Innovation)

The system evaluates multiple factors:

ML prediction (binary classification)

Risk probability score

Feature contribution via SHAP

Threshold-based risk interpretation

Example Policy:

Risk < 40% → Low risk

40% – 70% → Moderate risk

> 70% → High risk (Attention required)

This mirrors real clinical triage systems.
